# Explicación de código

## Propósito
Explicar código complejo en lenguaje natural, desglosándolo paso a paso para que sea comprensible para cualquier desarrollador.

## Flujo de trabajo
1. Leer y comprender el fragmento de código a explicar.
2. Identificar las funciones, clases, variables y estructuras de control principales.
3. Desglosar el flujo de ejecución paso a paso en lenguaje natural.
4. Explicar el propósito de cada bloque y cómo se relacionan entre sí.
5. Resumir el comportamiento general y los casos de uso del código.

## Reglas
- Usar lenguaje claro y evitar jargon innecesario.
- Explicar tanto el qué como el porqué del código.
- Señalar posibles complejidades o puntos de atención.
- Mantener la explicación fiel al código real, sin inventar comportamientos.
