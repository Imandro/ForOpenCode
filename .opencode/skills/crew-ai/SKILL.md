# Desarrollo con CrewAI

## Propósito
Desarrolla equipos de agentes colaborativos usando CrewAI, donde cada agente tiene un rol definido, herramientas asignadas y tareas específicas dentro de un flujo de trabajo orquestado. Úsala para automatizar procesos complejos que requieren división de trabajo entre agentes especializados.

## Flujo de trabajo
1. Define los agentes del equipo con sus roles, objetivos, historias de usuario y herramientas asignadas.
2. Crea las tareas con descripciones claras, resultados esperados y el agente responsable de cada una.
3. Organiza las tareas en un proceso (secuencial o jerárquico) con un manager opcional que coordine la ejecución.
4. Ejecuta el equipo (crew) supervisando la asignación de tareas y los resultados intermedios.
5. Evalúa los entregables finales y ajusta los roles, tareas o herramientas según sea necesario.

## Reglas
- Asigna a cada agente un rol bien definido y herramientas limitadas a su responsabilidad.
- Define resultados esperados medibles para cada tarea.
- Supervisa la ejecución de tareas críticas con revisión humana cuando sea necesario.
- Documenta el flujo de trabajo y las dependencias entre tareas del equipo.
