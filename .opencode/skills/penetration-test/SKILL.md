# Pruebas de penetración

## Propósito
Simula ataques reales contra sistemas, aplicaciones o redes para evaluar su resistencia y descubrir vulnerabilidades explotables. Úsala para validar la efectividad de los controles de seguridad y obtener una evaluación realista del riesgo bajo condiciones controladas.

## Flujo de trabajo
1. Define el alcance, objetivos y reglas de compromiso con el cliente o equipo.
2. Recopila información sobre el objetivo (reconocimiento pasivo y activo).
3. Identifica puntos de entrada y vulnerabilidades potenciales (escaneo y enumeración).
4. Intenta explotar las vulnerabilidades encontradas para demostrar impacto real.
5. Documenta cada hallazgo con pasos de reproducción, impacto y nivel de riesgo.
6. Entrega un informe con hallazgos, evidencia y recomendaciones de remediación.
7. Realiza una prueba de verificación tras la corrección de las vulnerabilidades.

## Reglas
- Obtén autorización escrita y firmada antes de iniciar cualquier prueba de penetración.
- Respeta estrictamente el alcance definido; no pruebes sistemas fuera de alcance.
- No causes denegación de servicio ni daños a datos ni sistemas del cliente.
- Maneja cualquier dato sensible encontrado con confidencialidad absoluta.
- No exploits vulnerabilidades en producción sin ventana de mantenimiento aprobada.
