# Snippets de código

## Propósito
Proporcionar fragmentos de código reutilizables organizados por lenguaje y patrón común, para acelerar el desarrollo evitando escribir desde cero soluciones frecuentes.

## Flujo de trabajo
1. Identificar el lenguaje de programación y el patrón o caso de uso necesario.
2. Buscar el snippet correspondiente en la colección de snippets.
3. Adaptar el snippet al contexto del proyecto (nombres de variables, importes, tipos).
4. Insertar el snippet en el archivo destino.
5. Verificar que el fragmento se integra correctamente con el código existente.

## Reglas
- Los snippets deben ser genéricos y no contener lógica de negocio específica.
- Mantener los snippets actualizados y probados.
- Documentar el lenguaje y el patrón al que pertenece cada snippet.
- No incluir dependencias innecesarias en los snippets.
