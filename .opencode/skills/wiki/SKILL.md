# Documentación de Wiki

## Propósito
Esta skill guía la creación y organización de documentación en formato wiki: páginas interconectadas, navegación, búsqueda y estructura de contenidos. Úsala cuando necesites un repositorio de conocimiento colaborativo, fácil de navegar y buscar, como una wiki de proyecto, base de conocimientos o documentación interna.

## Flujo de trabajo
1. Define el propósito y la audiencia de la wiki (equipo de desarrollo, usuarios finales, operaciones, etc.).
2. Establece una estructura de páginas con una página de inicio o portada que enlace a las secciones principales.
3. Crea páginas individuales usando Markdown, con títulos descriptivos y una introducción breve al inicio de cada una.
4. Añade enlaces internos entre páginas relacionadas para facilitar la navegación y el descubrimiento de contenido.
5. Implementa una tabla de contenidos o índice por sección para que los usuarios encuentren información rápidamente.
6. Establece convenciones de nombrado de archivos y uso de categorías o etiquetas para mejorar la búsqueda.

## Reglas
- Todos los paths dentro de esta skill son relativos al directorio que contiene este SKILL.md.
- Usa archivos Markdown (.md) para las páginas de la wiki.
- Cada página debe tener un título único y descriptivo (primer encabezado #).
- Usa enlaces relativos entre páginas para que la wiki sea portable.
- Mantén una página de inicio que sirva como punto de entrada y mapa del sitio.
- Evita páginas huérfanas: cada página debe estar enlazada desde al menos otra página o del índice.
