# Optimización SEO

## Propósito
Mejorar la visibilidad y el posicionamiento de una aplicación o sitio web en los motores de búsqueda mediante técnicas de SEO técnico y de contenidos. Úsala cuando necesites que los motores de búsqueda rastreen, indexen y posicionen correctamente tus páginas.

## Flujo de trabajo
1. Define una arquitectura de URL clara, amigable y con palabras clave relevantes.
2. Añade etiquetas meta (title, description) únicas y descriptivas en cada página.
3. Implementa datos estructurados (JSON-LD) para contenido como artículos, productos o preguntas frecuentes.
4. Genera y envía un sitemap.xml y configura un archivo robots.txt adecuado.
5. Asegura que el sitio cargue rápido, sea responsive y no tenga enlaces rotos ni contenido duplicado.

## Reglas
- Cada página debe tener una sola etiqueta <h1> y un title único de menos de 60 caracteres.
- La meta descripción debe ser atractiva, incluir la palabra clave principal y medir menos de 160 caracteres.
- Usa URLs legibles, en minúsculas y separadas por guiones, sin parámetros innecesarios.
- Implementa etiquetas canónicas para evitar problemas de contenido duplicado.
- Proporciona texto alternativo (alt) a las imágenes y transcripciones a contenidos multimedia.
