# Patrones de diseño

## Propósito
Aplicar patrones de diseño de software (creacionales, estructurales y de comportamiento) para resolver problemas de diseño recurrentes de forma probada y mantenible.

## Flujo de trabajo
1. Identificar el problema de diseño recurrente en el código.
2. Seleccionar el patrón de diseño más adecuado (creacional, estructural o de comportamiento).
3. Implementar el patrón siguiendo su estructura canónica y las mejores prácticas.
4. Integrar el patrón con el código existente sin romper la funcionalidad.
5. Documentar el patrón usado y su justificación en el código.
6. Ejecutar los tests para verificar que la implementación es correcta.

## Reglas
- No forzar un patrón donde no sea necesario; la simplicidad tiene prioridad.
- Conocer bien el patrón antes de implementarlo para evitar malos usos.
- Preferir composición sobre herencia cuando sea posible.
- Documentar la intención y las implicaciones de cada patrón aplicado.
