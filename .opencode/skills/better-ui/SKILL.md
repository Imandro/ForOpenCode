# Mejora de Interfaces de Usuario

## Propósito
Mejorar la usabilidad, el diseño visual, la accesibilidad y la experiencia de usuario de una aplicación. Se usa cuando se quiere que la interfaz sea más intuitiva, atractiva y usable para todo tipo de personas.

## Flujo de trabajo
1. Analizar la interfaz actual identificando problemas de usabilidad y accesibilidad.
2. Revisar los flujos de usuario críticos y los puntos de fricción.
3. Aplicar mejoras de diseño visual: espaciado, tipografía, colores y contraste.
4. Asegurar la accesibilidad: etiquetas ARIA, navegación por teclado, contraste de texto y lectores de pantalla.
5. Validar los cambios con pruebas de usuario o inspección heurística.

## Reglas
- Garantizar contraste suficiente entre texto y fondo (mínimo WCAG AA).
- Todos los elementos interactivos deben ser operables únicamente con teclado.
- Proporcionar texto alternativo y etiquetas descriptivas para imágenes y controles.
- Mantener una jerarquía visual clara y coherente en todas las pantallas.
