# Creación de README de proyectos

## Propósito
Esta skill guía la escritura de archivos README.md completos y bien estructurados para proyectos de software. Úsala cuando necesites documentar un proyecto desde cero, mejorar un README existente o estandarizar la presentación de un repositorio, incluyendo título, descripción, badges, instalación, uso, contribución y licencia.

## Flujo de trabajo
1. Define el título del proyecto y una descripción corta y clara en la parte superior del README.
2. Añade badges relevantes (estado de build, cobertura, versión, licencia, lenguaje) justo debajo del título.
3. Escribe una sección de instalación con los pasos necesarios para poner el proyecto en marcha (requisitos, comandos de instalación, variables de entorno).
4. Documenta la sección de uso con ejemplos de código, comandos de ejecución y casos de uso comunes.
5. Incluye secciones de contribución, licencia y contacto según las necesidades del proyecto.
6. Revisa que el README sea autónomo: cualquier persona nueva debe poder entender qué hace el proyecto y cómo empezar a usarlo sin leer otro documento.

## Reglas
- El nombre del archivo debe ser README.md y ubicarse en la raíz del repositorio.
- Todos los paths dentro de esta skill son relativos al directorio que contiene este SKILL.md.
- Usa títulos jerárquicos (# para el título principal, ## para secciones).
- Mantén los comandos de copia y pega listos para ejecutar en bloques de código.
- Incluye al menos una sección de instalación y una de uso.
- No incluyas secretos, claves API ni contraseñas reales en el README.
