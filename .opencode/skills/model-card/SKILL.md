# Tarjetas de Modelo (Model Cards)

## Propósito
Crea tarjetas de modelo que documenten de forma ética y técnica un modelo de inteligencia artificial. Úsala para proporcionar transparencia sobre el propósito, el rendimiento, las limitaciones, los sesgos y el uso previsto de un modelo antes de compartirlo o desplegarlo.

## Flujo de trabajo
1. Describe el propósito del modelo, sus desarrolladores y la fecha de creación.
2. Documenta los datos de entrenamiento: origen, tamaño, composición y preprocesamiento.
3. Reporta métricas de rendimiento disagregadas por grupos relevantes y en diferentes escenarios.
4. Identifica limitaciones conocidos, sesgos potenciales y casos en los que el modelo no debe usarse.
5. Especifica las condiciones de uso, licencias, responsable de mantenimiento y datos de contacto.

## Reglas
- Sé honesto sobre las limitaciones y fallos conocidos del modelo.
- Incluye métricas de equidad y sesgo cuando el modelo afecte a personas.
- Actualiza la tarjeta cada vez que el modelo o sus datos de entrenamiento cambien.
- Usa un lenguaje accesible para usuarios no técnicos además de detalles técnicos para desarrolladores.
