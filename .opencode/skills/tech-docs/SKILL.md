# Documentación Técnica para Desarrolladores

## Propósito
Esta skill guía la creación de documentación técnica dirigida a desarrolladores: guías de inicio rápido, tutoriales paso a paso, referencia de API y conceptos arquitectónicos. Úsala cuando necesites documentar cómo funciona un sistema, cómo integrarse con él o cómo extenderlo, dirigida a un público técnico.

## Flujo de trabajo
1. Identifica la audiencia (desarrolladores internos, consumidores de API, colaboradores externos) y el objetivo de la documentación.
2. Organiza la documentación en carpetas lógicas: guías, tutoriales, referencia y conceptos.
3. Escribe una guía de inicio rápido que permita a un desarrollador ejecutar un ejemplo funcional en pocos minutos.
4. Crea tutoriales paso a paso para tareas comunes, con requisitos previos, comandos y resultados esperados.
5. Documenta la referencia técnica con firmas de funciones, parámetros, valores de retorno y ejemplos de uso.
6. Incluye un índice o README que oriente al lector sobre por dónde empezar según su objetivo.

## Reglas
- Todos los paths dentro de esta skill son relativos al directorio que contiene este SKILL.md.
- Usa Markdown para los archivos de documentación.
- Cada guía o tutorial debe tener un título claro, requisitos previos y pasos numerados.
- Incluye bloques de código con el lenguaje especificado para resaltado de sintaxis.
- Mantén la referencia técnica actualizada con el código real; documenta parámetros obligatorios y opcionales.
- Evita jerga innecesaria y explica los términos técnicos al introducirlos por primera vez.
