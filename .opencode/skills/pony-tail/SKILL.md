# Estilo de Código "Cola de Caballo"

## Propósito
Aplicar un estilo de código limpio, ordenado y uniforme en todo el proyecto. Se usa cuando se quiere mejorar la legibilidad del código, establecer convenciones de nombres y dar una presentación consistente, como si el código estuviera peinado hacia atrás.

## Flujo de trabajo
1. Revisar el estilo de código existente del proyecto y su configururación de formateo.
2. Aplicar el formateador automático correspondiente a cada archivo fuente.
3. Renombrar variables, funciones, clases y archivos siguiendo las convenciones del proyecto.
4. Eliminar código comentado, imports no utilizados y espacios en blanco innecesarios.
5. Verificar que el código formateado sigue compilando y pasando las pruebas.

## Reglas
- Mantener una indentación y ancho de línea consistentes en todos los archivos.
- Usar nombres descriptivos en español o inglés según la convención del proyecto, sin mezclar ambos sin motivo.
- No dejar código muerto, comentarios obsoletos ni imports sin usar.
- Respetar la configuración de formateo del proyecto (EditorConfig, Prettier, gofmt, etc.).
